PatahPensill Live Screener
Data diambil langsung dari endpoint publik Binance Futures (fapi.binance.com) tanpa API key — semua proses berjalan di browser lo, bukan di server saya. "Quick Score" dihitung dari data 24 jam (volume, volatilitas, posisi harga dalam range). "Deep Signal" dihitung dari RSI(14) 1H dan tren EMA21 vs EMA50 di 4H, hanya untuk pair yang di-scan manual — untuk membatasi jumlah request dari HP lo. Tap baris pair untuk lihat indikator lengkap: EMA21/30, MA200, Anchored VWAP + Band (0.5σ), Fibonacci, MACD, StochRSI, ATR, Bollinger Bands, ADX (kekuatan tren), Struktur Market (swing HH/HL vs LH/LL + BOS/CHoCH — dibobot 2x sebagai penilaian utama), Funding Rate, Open Interest, dan konfluensi multi-timeframe (trend + struktur, 1H/4H/1D), plus skor Long/Short. Kolom FUNDING menampilkan funding rate terkini tiap pair. Tandai pair dengan ⭐ untuk masuk Watchlist — pair di Watchlist otomatis dicek untuk alert RSI ekstrem, funding ekstrem, harga mendekati level struktural (EMA21/EMA30/MA200/AVWAP+Band/Fibonacci di 4H), dan Change of Character (CHoCH) struktur market di 4H, tiap Auto-Refresh. Semua data (watchlist, riwayat alert, pengaturan) tersimpan lokal di HP/browser lo saja. Ini bukan rekomendasi finansial, hasil dari struktur teknikal murni. Kalau data gagal dimuat, kemungkinan ISP/provider lo memblokir akses ke domain Binance — coba pakai VPN atau jaringan lain.
