Data diambil langsung dari endpoint publik Binance Futures (fapi.binance.com) tanpa API key — semua proses berjalan di browser lo, bukan di server saya. "Quick Score" dihitung dari data 24 jam (volume, volatilitas, posisi harga dalam range). "Deep Signal" dihitung dari RSI(14) 1H dan tren EMA21 vs EMA50 di 4H, hanya untuk pair yang di-scan manual — untuk membatasi jumlah request dari HP lo. Tap baris pair untuk lihat indikator lengkap (EMA21, EMA30, MA200, VWAP, Fibonacci) dan skor Long/Short. Ini bukan rekomendasi finansial, hasil dari struktur teknikal murni. Kalau data gagal dimuat, kemungkinan ISP/provider lo memblokir akses ke domain Binance — coba pakai VPN atau jaringan lain.
